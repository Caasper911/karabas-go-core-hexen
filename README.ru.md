# Ядро Heretic для Karabas Go / Mini / Mini G

[English version](README.md)

Heretic для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25): софт-процессор VexRiscv (RISC-V) на 75 МГц исполняет Heretic из [Chocolate Doom](https://github.com/chocolate-doom/chocolate-doom) 2.3.0; буфер кадра, палитра, микшер звука, OPL3 и MIDI-синтезатор платы — в ПЛИС. Прошивка ПЛИС та же, что у ядра Doom этого семейства; отличается только программа.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `heretic.kg` | VGA | ЦАП I2S (PCM5102); MIDI-синтезатор только на аналоговом выходе |
| Karabas Mini | `heretic.kg` | HDMI | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `heretic.kg` | HDMI | HDMI, ЦАП I2S |

Файл ядра лежит в `src/`. Данных игры в нём нет: положите на SD-карту свой `HERETIC.WAD` (полная версия) или шареварный `HERETIC1.WAD`.

Состояние: работает на Mini G (шареварный HERETIC1.WAD 1.2); в симуляторе также проверены эффекты, музыка OPL3 и MIDI, сохранения. Сборки Go и Mini на плате ещё не запускались.

## Возможности

- **Скорость:** ожидается около 25 кадров в секунду в игре (модель по симулятору; игра Heretic идёт с частотой 35 тиков в секунду).
- **Видео:** 320 x 200, 256 цветов, удвоено до 640 x 400 в середине 640 x 480 при 60 Гц.
- **Звуковые эффекты:** 8 каналов, микширует процессор, 11025 Гц, с изменением высоты звука, как в Heretic.
- **Музыка:** OPL3 FM (инструменты GENMIDI из WAD, как в Chocolate Doom) или MIDI-синтезатор платы (SAM2695), выбор в OSD.
- **Сохранения:** 6 сохранений и настройки (`heretic.cfg`, `chocolate-heretic.cfg`, пишутся при выходе из игры) хранятся в `<папка WAD>/saves/<имя WAD>.sav` (1 МБ, создаёт прошивка; нужна прошивка 26111813 или новее).
- **Управление:** USB-клавиатура, мышь, USB-геймпад.

Не сделано: PWAD (загружается только один IWAD), сетевая игра.

## Как начать

1. Скопируйте `heretic.kg` (один файл для Go, Mini и Mini G) в корень SD-карты.
2. Положите WAD в `/heretic` на SD-карте.
3. Выберите Heretic в меню ядер. В первый раз откройте OSD (**Menu+Esc**) и выберите WAD (**Menu+F1**); при следующих запусках ядро загрузит последний WAD само.

«Menu» — клавиша Windows на клавиатуре.

## Меню OSD

| Пункт | Значения | Клавиша |
|---|---|---|
| WAD | файл `.wad` (загружается при старте ядра) | Menu+F1 |
| Music | MIDI / OPL3 / Off | Menu+M |
| Controls | Classic / WASD (см. ниже) | |
| Mouse move | Off / On: мышь двигает и вперёд-назад (Off — только поворот) | |
| Reset | перезапуск Heretic | F12 |

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ход, поворот | стрелки (WASD: также W / S, A / D — шаг вбок) | крестовина |
| Огонь | Ctrl, левая кнопка мыши | A |
| Использовать (двери, рычаги) | пробел (WASD: также E, правая кнопка мыши) | B |
| Бег | Shift | C |
| Шаг вбок | Alt (со стрелками), `,` / `.` | |
| Оружие | 1 .. 7 | Mode: следующее |
| Инвентарь | `[` / `]` выбор, Enter применить | Z / Y выбор, Start применить |
| Полёт вверх / вниз / стоп | PgUp / Ins / Home | |
| Взгляд вверх / вниз / прямо | PgDn / Del / End | |
| Меню | Esc, Enter | X, Start |
| Карта | Tab | |
| Сохранить / загрузить | F2 / F3 | |

Кнопки мыши в Classic: левая — огонь, правая — шаг вбок, средняя — вперёд. Работают оба геймпада (кнопки те же). В WASD буквы W, A, S, D, E работают как игровые только вне меню (имена сохранений набираются как обычно); чит-коды с ними в этом режиме не работают.

Остальные клавиши — как в Heretic (F1 помощь, F5 детализация, F6 быстрое сохранение, F9 быстрая загрузка, F11 гамма, `-` / `=` размер экрана, Backspace / `\` / 0 / 5 .. 9 артефакты).

## Сборка

Программа процессора — в `src/fw` (xPack riscv-none-elf-gcc 15.2): `make htic-hw` (для платы), `make htic` (стенд симулятора). `src/Makefile`: `make rom`, затем `make kg` (.kg из битстримов в git) или `make minig` / `make mini` / `make go` через ISE 14.7. Устройство, замеры и история (сверху Heretic, ниже Doom) — в `docs/PLAN.md`.
